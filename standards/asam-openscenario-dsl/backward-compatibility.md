# 5 Backward compatibility

This version of ASAM OpenSCENARIO DSL is the second release of this standard.
The first release was named [ASAM OpenSCENARIO® 2.0.0](../v2.0.0/index.html).
With the first release, two separate versions of the standard ASAM OpenSCENARIO were being maintained in parallel, delineated by the major version 1.x or 2.x.
To prevent confusion, ASAM split these into two separate standards, ASAM OpenSCENARIO XML (previously 1.x) and ASAM OpenSCENARIO DSL (this standard, previously 2.x).
Each version of the standard is now separately versioned.
Releases of ASAM OpenSCENARIO XML are based on an XML representation and are not compatible with this standard.

ASAM plans to continue the evolution of both ASAM OpenSCENARIO DSL and ASAM OpenSCENARIO XML to meet market requirements.
Please refer to the [ASAM web page](https://www.asam.net/standards/detail/openscenario-dsl/) for further details.
ASAM does not directly support conversion between the two standards.

In the first release of ASAM OpenSCENARIO, a migration guide was supplied, with guidance and direction on how to migrate from ASAM OpenSCENARIO XML 1.2.0.
This guide is no longer being updated.
Based on market demand, it is expected that solution suppliers will develop solutions to convert scenarios from ASAM OpenSCENARIO XML to this version of ASAM OpenSCENARIO DSL.
