## B.11.2 Creating natural language scenarios

### B.11.2.1 Workflow short description

As a stakeholder, I can create natural language scenarios without having any knowledge about technical details.

### B.11.2.2 Workflow detailed description

A stakeholder without knowledge about technical details must be able to describe a scenario using natural language.

It must be possible to share a scenario defined this way with technically skilled people.
It must also be possible to convert such a scenario into real code by technical experts.

### B.11.2.4 Steps to create natural language scenarios without technical details

As the need of a new Scenario arises, the task of developing such a scenario may be given to a stakeholder that does not have the skills and knowledge of technical details about ASAM OpenSCENARIO.

This is not a blocking point, as ASAM OpenSCENARIO allows for scenarios described in *natural language*.
The stakeholder can then use his *normal* language to describe how the scenario should evolve, and then share it with more technically skilled people.

It is up to them then to translate this scenario into ASAM OpenSCENARIO compliant code.
Such a workflow empowers almost any user to write scenarios using ASAM OpenSCENARIO.

At the end of this process, the stakeholder has a scenario described in natural language, ready to be converted into ASAM OpenSCENARIO format by technically skilled people.
