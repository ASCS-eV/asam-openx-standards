# 8.2 Domain model core layout

The following sections contain the core layout of the domain model.

Before continuing, make sure to be familiar with  [Section 3, "Terms and definitions"](../terms_and_definitions.html).
For a more detailed description of key terminology, refer to  [Section 6.2, "Key terminology"](../conceptual-overview/key_terms.html).

The entities of the domain model and their sub-classes are described with their definitions, states, properties, and relations to other classes.
Unless noted otherwise (for example, for [Physical type](physical_types.html)) all definitions reside in the `std` namespace and form part of `domain` sub-module of the standard library.

The following entities are available:

* [Physical object](entity.html#sec-dm-entities-physical-objects)
* [Environment](environment-actors.html#sec-dm-entities-environment)
* [Action](actions.html)
* [Physical type](physical_types.html)
* [Primitive type](primitive_types.html)
* [Road abstraction](road_abstractions.html#top-dm-road-abstractions)
* [Behavioral model](dm_behavioral_model.html#top-dm-behavioral-model)
