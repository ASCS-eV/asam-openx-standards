# ASAM OpenODD® v1.0.0 — §1 Scope

> **Standard**: ASAM OpenODD® Base Standard 1.0.0 Specification, 2025-04-03
> **License**: Unrestricted distribution (ASAM e.V.)
> **Downloaded**: 2026-05-19

---

ASAM OpenODD® specifies a modeling approach and exchange formats to specify and describe operational design domain for automated driving systems. In addition, the specification includes modeling of operational domain, current operational domain, and target operational domain. The ASAM OpenODD® standard has the following scope:

- Specify the ASAM OpenODD® model as a UML model. The UML model defines how taxonomies and taxonomy concepts are represented and how modeling is done using modules with sections including multiple expressions.

- Explain all ASAM OpenODD® elements and their relations.

- Specify mapping references to use the ASAM OpenODD® model in different formats such as a tabular format or the languages YAML and ASAM OpenSCENARIO® DSL.

- The standard includes informative best practices for using the mapping references.

A standard compliant implementation shall be fully conform with one of the mapping references.
